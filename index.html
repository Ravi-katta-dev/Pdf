Units & Measurements Concepts

Fundamental Units

The seven fundamental units are the basic units of measurement in the International System of Units (SI):

  • Length: meter (m)
  • Mass: kilogram (kg)
  • Time: second (s)
  • Electric Current: ampere (A)
  • Thermodynamic Temperature: kelvin (K)
  • Amount of Substance: mole (mol)
  • Luminous Intensity: candela (cd)

Derived Units

Derived units are formed by combining fundamental units:

  • Area: m² (square meter)
  • Volume: m³ (cubic meter)
  • Velocity: m/s (meter per second)
  • Acceleration: m/s² (meter per second squared)
  • Force: N (Newton) = kg⋅m/s²
  • Energy: J (Joule) = kg⋅m²/s²
  • Power: W (Watt) = kg⋅m²/s³

Dimensional Analysis

Dimensional analysis is a method to check equations and convert units using the dimensions of physical quantities.

Key Points:

  • Only quantities with the same dimensions can be added or subtracted
  • Both sides of an equation must have the same dimensions
  • Trigonometric functions are dimensionless
  • Arguments of exponential and logarithmic functions must be dimensionless

Significant Figures

Rules for significant figures in measurements and calculations:

  • All non-zero digits are significant
  • Zeros between non-zero digits are significant
  • Leading zeros are not significant
  • Trailing zeros after the decimal point are significant
  • In multiplication/division: result has fewest significant figures
  • In addition/subtraction: result has fewest decimal places

Errors in Measurement

Types of errors and their calculation:

  • Systematic Error: Consistent error in one direction
  • Random Error: Unpredictable variations in measurements
  • Absolute Error: |Measured Value - True Value|
  • Relative Error: (Absolute Error / True Value) × 100%
  • Percentage Error: Relative Error expressed as percentage
